## What is 7.Orbits?

7.Orbits is an open-source organization with one clear goal: **build tools that actually help people get things done** — regardless of their technical background.

We believe the best software is the kind that doesn't ask you to learn before you can use it. Every project we ship is designed with both developers and non-developers in mind, free to use, and open to contributions from anyone.

---

## What we stand for

**Accessible by design.**
We don't build for a specific type of user. If a tool only works for developers, we haven't finished building it yet.

**Open-source, always.**
Every project under 7.Orbits is open-source — not as an afterthought, but as a principle. The code is yours to read, fork, learn from, and improve.

**Tools that matter.**
We don't ship features for the sake of shipping. Every project starts with a real problem that real people face.

**Built with contributors, not just for them.**
The community shapes what we build. If you have an idea, an opinion, or a fix — you have a place here.

## Getting involved

We welcome contributors at every level — from first-timers opening their first pull request to experienced engineers looking for meaningful open-source work.

```bash
# Pick a repository you're interested in
# Browse open issues — look for "good first issue" to get started

git clone https://github.com/7-Orbits/<repo-name>.git
git checkout -b your-branch-name

# Make your changes, then open a pull request
```

**Ways to contribute:**

- Fix bugs or open issues you find
- Improve documentation and guides
- Propose or build new features
- Share feedback on existing tools
- Help translate projects for more users

Not sure where to start? Open a [Discussion](https://github.com/orgs/7-Orbits/discussions) — we're happy to point you in the right direction.
